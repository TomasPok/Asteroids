# Asteroids

A classic Asteroids arcade game built with Python and Pygame.

## Features

- Player-controlled ship with rotation and movement
- Game loop with delta-time (`dt`) updates
- Sprite management using Pygame `Group` containers (`updatable` and `drawable`)
